# Convex Feedback Monorepo

A strict-TypeScript monorepo containing:

- **`convex-feedback`** — a headless Convex component for feedback, feature requests, bug reports, entry upvotes, lazy recursive comments, comment likes, and full-text duplicate suggestions.
- **`convex-feedback-ui`** — optional compound UI primitives and prebuilt screens for React DOM and React Native.

The repository follows the current Convex component starter layout: component functions live under `src/component`, host-facing wrappers under `src/client`, React hooks under `src/react`, the component config is exported as a package entry point, and `/test` exposes a `convex-test` registration helper.

## Design invariants

1. There are exactly three component tables: `entries`, `comments`, and `reactions`.
2. The component does not own users and does not depend on an authentication provider.
3. Host code resolves a stable actor id and moderator flag before calling the component.
4. All component functions have argument and return validators.
5. Handwritten TypeScript must not use explicit or unsafe `any` escapes. Generated Convex files are excluded from this rule and are regenerated by Convex.
6. Recursive comments are lazy: a comments query returns one direct-child level only. Opening a comment mounts a separate paginated query for that comment's children.
7. Server-side comment ordering is index-backed: `top`, `newest`, or `oldest`.
8. Search is Convex full-text search plus a normalized-title exact-duplicate index. No embeddings, vector table, background job, or search mirror table is used.
9. The headless package never imports `convex-feedback-ui`.
10. Package-owned UI text is supplied through the typed `FeedbackMessages` contract. User content is never translated or modified.

## Development

```bash
npm install
npm run codegen
npm run check
```

`npm run codegen` regenerates the component's `_generated` files using Convex. Commit generated output after schema or function changes.

### Workspace install lifecycle

The packages intentionally do **not** use an npm `prepare` script. The standalone Convex component starter builds during `prepare`, but in this monorepo npm may prepare `convex-feedback-ui` before `convex-feedback/dist` exists. Publishing uses `prepack` instead, while the root `build` script deterministically builds `convex-feedback` first and `convex-feedback-ui` second. This keeps `npm install` side-effect free and prevents workspace-order build failures.

## Host integration

Mount the component in the host application's `convex.config.ts`:

```ts
import { defineApp } from "convex/server";
import feedback from "convex-feedback/convex.config.js";

const app = defineApp();
app.use(feedback);
export default app;
```

Then expose the component through the host authentication boundary:

```ts
import { exposeFeedbackApi } from "convex-feedback";
import { components } from "./_generated/api";

export const {
  listEntries,
  getEntry,
  searchEntries,
  findSimilarEntries,
  createEntry,
  updateEntry,
  setEntryStatus,
  setEntryUpvote,
  listComments,
  createComment,
  updateComment,
  deleteComment,
  setCommentLike,
} = exposeFeedbackApi(components.feedback, {
  actor: async (ctx) => {
    const identity = await ctx.auth.getUserIdentity();
    return identity === null
      ? null
      : { id: identity.subject, isModerator: false };
  },
});
```

The component itself does not call the host app's `ctx.auth`; that responsibility intentionally stays in this wrapper.

## React hooks

```ts
import { createFeedbackHooks } from "convex-feedback/react";
import { api } from "./convex/_generated/api";

export const feedbackHooks = createFeedbackHooks(api.feedback, {
  entryPageSize: 20,
  commentPageSize: 20,
  replyPageSize: 10,
});
```

## Prebuilt web UI

```tsx
import { FeedbackScreen } from "convex-feedback-ui";
import "convex-feedback-ui/styles.css";

<FeedbackScreen
  hooks={feedbackHooks}
  primaryColor="#5b5bd6"
  messages={{ board: { title: "Product feedback" } }}
/>;
```

## Prebuilt native UI

```tsx
import { FeedbackScreen } from "convex-feedback-ui/native";

<FeedbackScreen
  hooks={feedbackHooks}
  theme={{ colors: { primary: "#5b5bd6" } }}
/>;
```
